مشروع قاصتي جاهز للتحويل إلى APK

الطريقة الأسهل:
1) افتح Android Studio.
2) اختر Open وافتح مجلد qasati-apk-ready.
3) انتظر انتهاء Gradle Sync.
4) من القائمة: Build > Build Bundle(s) / APK(s) > Build APK(s).
5) ستجد ملف APK داخل:
app/build/outputs/apk/debug/app-debug.apk
6) انقل APK إلى هاتفك وثبته.

ملاحظة:
هذا التطبيق يحوّل ملف HTML إلى تطبيق Android WebView.
تم وضع الشعار كواجهة داخل التطبيق وكأيقونة للتطبيق.
